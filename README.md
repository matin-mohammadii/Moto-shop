# 🏍️ MOTO SHOP | فروشگاه اینترنتی موتورسیکلت

یک فروشگاه اینترنتی ساده برای نمایش و فروش محصولات مرتبط با موتورسیکلت که با استفاده از فریم‌ورک Django توسعه داده شده است.

## 📌 معرفی پروژه

هدف از ساخت این پروژه، طراحی یک فروشگاه اینترنتی با قابلیت مشاهده محصولات، ثبت سفارش و مدیریت اطلاعات محصولات و سفارش‌ها است.

این پروژه با زبان Python و فریم‌ورک Django توسعه داده شده و به‌عنوان یک پروژه آموزشی برای یادگیری توسعه بک‌اند وب طراحی شده است.

## ✨ امکانات پروژه

- نمایش فهرست محصولات
- مشاهده جزئیات هر محصول
- جست‌وجوی محصولات
- ثبت‌نام و ورود کاربران
- مدیریت سبد خرید
- ثبت سفارش محصولات
- مشاهده تاریخچه سفارش‌ها
- مدیریت محصولات و سفارش‌ها از طریق پنل مدیریت Django
- مدیریت موجودی محصولات
- امکان بارگذاری تصاویر محصولات

## 🛠️ تکنولوژی‌های استفاده‌شده

- Python
- Django
- SQLite
- HTML
- CSS

## ⚙️ نحوه اجرای پروژه

ابتدا مخزن پروژه را دریافت کنید:

```bash
git clone https://github.com/matin-mohammadii/Moto-shop.git
```

وارد پوشه پروژه شوید:

```bash
cd Moto-shop
```

وابستگی‌های موردنیاز را نصب کنید:

```bash
pip install django
```

سپس دستورات زیر را اجرا کنید:

```bash
python manage.py migrate
```

در نهایت سرور توسعه را اجرا کنید:

```bash
python manage.py runserver
```

حالا از طریق آدرس زیر وارد فروشگاه شوید:

```text
http://127.0.0.1:8000/
```
